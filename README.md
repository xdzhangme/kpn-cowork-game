# KPN Cowork game

A static 2D pixel-art office tutorial game for KPN employees, built with Vite and a plain HTML Canvas. No backend, no frameworks. Players walk through a pixel office, open one of 50 real KPN Cowork use cases and watch a short four-act scenario (Situation, Prompt, Run, Outcome) that shows what Cowork does with that case and why it beats pasting files into Copilot Chat. See `docs/PRD.md`, `docs/VISUAL-SPEC.md` and `docs/USE-CASE-SCHEMA.md`.

This repository was generated from the template `xdzhangme/simple-game-art-try` and customised for KPN (logo, brand colours, departments and use cases).

## Run locally

Requires Node.js 20+.

```sh
npm install
npm run dev      # dev server with hot reload
npm run build    # production build into dist/
npm run preview  # serve the built site locally
```

## Editing content

All content is static data; no code changes are needed.

- **Use cases:** the KPN source data lives in `public/data/kpn-use-cases-en.json` and `public/data/kpn-use-cases-nl.json` (50 cases each, same ids in the same order). The schema is described in `docs/USE-CASE-SCHEMA.md`. The `credits` field is never displayed. Replace both files with a newer export to update the content.
- **Hand-polished scenarios:** `src/data/scenario-overrides.json` adds richer situation messages, file lists and deliverable previews for selected cases (currently CON-01, GEN-01 and FIN-01). Anything not overridden is generated from the use-case fields. Dutch falls back to English per field.
- **Chat vs Cowork explainer:** `src/content/intro.json` (the screens shown in the intro room).
- **How to start / Responsible AI / Disclaimer pages:** edit `src/content/pages.json` (one block per language). How to start mirrors the in-game guide: play a case, Copy prompt, Open Cowork, review, share.
- **How to play guide:** the six first-visit screens (reopened with the header Guide button or How to play in the bottom bar) are the `tutorial.*` strings in `src/i18n.js`.
- **UI strings and translations:** edit `src/i18n.js` (room names, scenario labels, comparison panel text).
- **Theme colors:** edit `public/theme.json` (KPN tokens by default; outline, wall, floor, accent, panel, marker, done, locked, ink and so on). It is loaded at runtime, so it can be changed in the deployed `dist/` without a rebuild. Site chrome tokens live at the top of `src/style.css`.
- **Logo, name and Cowork link:** `src/config.js` (`companyName`, `badge`, `logo`, `coworkUrl`); the logo file is `public/kpn-logo.svg`. `coworkUrl` is the target of every Open Cowork button and currently points to the generic Microsoft 365 Copilot entry point; replace it with KPN's Cowork entry URL when available.
- **Office map:** `src/data/office-map.json` is generated by `npm run build:map` (`scripts/build-map.mjs`). Rooms map to KPN departments; the General room holds the GEN cases and the Chat vs Cowork room holds the explainer.

Check your edits with:

```sh
npm run validate    # use-case JSON (en + nl parity) and scenario overrides
npm run check:map   # every use-case object is reachable on the map
```

Progress (completed case ids, "tried at work" flags), language and sound settings are stored in the browser's `localStorage`.

## Testing

Before a release, run `npm run validate`, `npm run check:map` and `npm run build`, then walk through `docs/SMOKE-CHECKLIST.md` on the deployed site.

## Deploy

`.github/workflows/deploy.yml` builds the site and publishes `dist/` to GitHub Pages on every push to `main` (or manually via "Run workflow"). The site is served under `/kpn-cowork-game/`; the build uses relative asset paths so no base-path change is needed.

One-time setup: in the repository, go to **Settings > Pages** and set **Source** to **GitHub Actions**.
